## Decisiones de diseño y desarrollo
El diseño está inspirado en Pokémon Esmeralda, utilizando una paleta de verdes, celestes y amarillos, e imagenes para darle una identidad visual reconocible.

Se utilizó Flexbox y Grid para organizar el contenido y facilitar su adaptación a distintas pantallas.
El carrusel de experiencia se realizó únicamente con HTML y CSS, utilizando radio buttons para cambiar entre años sin depender de JavaScript. Del mismo modo, el menú de navegación utiliza un checkbox como toggle para controlar su apertura y cierre sin JavaScript. También se incorporaron animaciones y transiciones para hacer la interacción más dinámica. Se aplicó un diseño responsive mediante media queries para adaptar la distribución del contenido a dispositivos móviles.

Se utilizaron herramientas de inteligencia artificial como apoyo durante el desarrollo, principalmente para agilizar la redacción de textos.
